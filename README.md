# S&P 500 Investing Guide

An educational website about investing in the S&P 500, with an interactive growth calculator.

## Features
- What the S&P 500 is and how to invest in it
- Interactive calculator: initial investment, monthly income, % invested, income growth, years, expected return, fees and inflation
- Live chart (portfolio value, total contributed, inflation-adjusted value) plus a year-by-year table
- Key principles, FAQ, a short quiz and a glossary
- Special thanks to Ray Sumler
- Light and dark mode, mobile friendly

## Publish with GitHub Pages
1. Create a new repository on GitHub and upload `index.html`, `README.md` and the `images` folder.
2. Go to **Settings → Pages**.
3. Under **Source**, choose **Deploy from a branch**, select `main` and `/ (root)`, then **Save**.
4. After a minute your site will be live at `https://<your-username>.github.io/<repo-name>/`.
